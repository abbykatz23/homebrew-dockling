# homebrew-dockling

Homebrew tap for [Dockling](https://github.com/abbykatz23/dockling).

```
brew install --cask abbykatz23/dockling/dockling
```

`Casks/dockling.rb` is updated automatically by a GitHub Actions workflow in
the main Dockling repo every time a new release is published there — it's
not meant to be edited by hand.
